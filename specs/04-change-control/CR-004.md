## Requested Change

Provide a verified startup procedure and database setup script so the
E-Bookstore application (backend + frontend) can be started locally by
the project owner with a single command per terminal.

---

## Problem Statement

The application is fully implemented and all 80 tests pass. However the
project owner has not yet run the application end-to-end. The following
gaps prevent a clean first startup:

1. **Database does not exist yet.** PostgreSQL is required at
   `localhost:5432`. The database `ebookstore` and its schema are created
   by Flyway migrations (V1–V8) on first boot — but only if the database
   itself already exists.

2. **No one-step startup guide exists.** The startup procedure (activate
   `local` profile, run Vite dev server) is not documented in a single
   reachable place for the project owner.

3. **`application-local.properties` port/password may not match the local
   PostgreSQL install.** CR-003 set `password=root` and `port=8081`.
   If the local PostgreSQL password differs, the backend will fail to
   connect on first attempt.

---

## Proposed Solution

Produce the following, each requiring explicit human approval before execution:

### Step 1 — Database Setup Script (new file)
Create `ebookstore/script/setup_db.sql` — a one-time SQL script that:
- Creates the `ebookstore` database (if it does not exist).
- Creates the `postgres` role if missing (no-op on most installs).

This script is run **once**, manually, before first boot.

### Step 2 — Startup Guide (new file)
Create `ebookstore/docs/STARTUP_GUIDE.md` documenting:
- Prerequisites (Java 21, Node 20+, PostgreSQL 16+, Maven wrapper).
- How to verify PostgreSQL is running.
- How to run the database setup script.
- Exact command to start the backend (`local` profile).
- Exact command to start the frontend (`npm run dev`).
- Expected startup log lines.
- URLs: frontend `http://localhost:5173`, backend `http://localhost:8081`.

### Step 3 — CORS verification
Verify that the backend `SecurityConfig` / CORS configuration allows
`http://localhost:5173` (Vite default port). Fix if missing.
